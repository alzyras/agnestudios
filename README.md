# Agne Studios — local portfolio

A responsive local portfolio recreation based on the Agne Studios Figma design. The project artwork used by the galleries is stored in `assets/figma/`.

## Run locally

```sh
npm run dev
```

Open [http://127.0.0.1:4174](http://127.0.0.1:4174). The home view starts empty. The red line snaps to the hovered project row and disappears when the pointer leaves the list. Click a project to open its artwork; click outside a row or use the arrow keys to browse that gallery.

The studio name and “about” link open the About page. Click the studio name there or press Escape to return to the portfolio.
